# Requisitos del producto (PRD)

Esta carpeta guarda los documentos de requisitos del producto: qué problema se resuelve, para quién, qué reglas aplican
y cómo se comprueba que está resuelto. No describe cómo se implementa: eso va en
[arquitectura](../arquitectura/README.md) y en los [planes](../plans/README.md).

- Un archivo por funcionalidad o iniciativa, con un nombre que la identifique.
- [ejemplo-tareas.md](./ejemplo-tareas.md) es un PRD de ejemplo de la funcionalidad `tasks` que incluye la plantilla.
  Sirve de modelo de formato y se elimina al retirar esa funcionalidad.
