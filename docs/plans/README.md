# Planes de implementación

Esta carpeta guarda los planes de implementación: los pasos ordenados para construir un cambio. Un plan es un artefacto
de trabajo temporal. La documentación de [arquitectura](../arquitectura/README.md) y las
[guías](../guias/general/README.md) describen el resultado por sí mismas y no enlazan a los planes.

- Un archivo por cambio, que parte de un [PRD](../prd/README.md) o de una petición concreta.
- [ejemplo-tareas.md](./ejemplo-tareas.md) es un plan de ejemplo de la funcionalidad `tasks` que incluye la plantilla.
  Sirve de modelo de formato y se elimina al retirar esa funcionalidad.
