# Planes de implementación

Esta carpeta guarda los planes de implementación: los pasos ordenados para construir un cambio. Un plan es un artefacto
de trabajo temporal. La documentación de [arquitectura](../arquitectura/README.md) y las [guías](../guias/) describen el
resultado por sí mismas y no enlazan a los planes.

- Un archivo por cambio, que parte de un [PRD](../prd/README.md) o de una petición concreta.
- [ejemplo-estado-y-cuenta.md](./ejemplo-estado-y-cuenta.md) es el plan de las páginas de estado y de cuenta que incluye
  la plantilla, con sus fases, tareas y criterios de aceptación. Sirve de modelo de formato y se elimina al retirar esas
  páginas.
