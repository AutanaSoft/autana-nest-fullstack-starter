# Política de seguridad

## Cómo reportar una vulnerabilidad

No abras un issue público para reportar una vulnerabilidad. Usa el
[reporte privado de vulnerabilidades de GitHub](https://github.com/AutanaSoft/autana-nest-fullstack-starter/security/advisories/new)
desde la pestaña **Security** del repositorio.

Incluye una descripción del problema, los pasos para reproducirlo y su posible impacto.

## Alcance

Este repositorio es una plantilla de inicio. Los reportes se refieren al código que contiene; la seguridad de los
proyectos creados a partir de ella es responsabilidad de quien los mantiene.
