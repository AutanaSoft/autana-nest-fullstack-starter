# Código de conducta

Este proyecto adopta el
[Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## Compromiso

Nos comprometemos a que participar en este proyecto sea una experiencia libre de acoso para todas las personas. Se
espera un trato respetuoso, constructivo y profesional en issues, pull requests y demás espacios del proyecto.

## Conductas inaceptables

- Insultos, acoso, discriminación o ataques personales.
- Publicar información privada de otras personas sin su permiso.
- Cualquier conducta que se considere razonablemente inapropiada en un entorno profesional.

## Aplicación

Las personas mantenedoras pueden editar o eliminar contenido y limitar la participación de quien incumpla estas normas.
Para reportar una conducta inapropiada, contacta con las personas mantenedoras a través de
[AutanaSoft](https://autanasoft.com).
