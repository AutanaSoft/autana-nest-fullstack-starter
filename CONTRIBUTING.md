# Contribuir

Gracias por tu interés en mejorar este proyecto.

## Primeros pasos

Los requisitos, la configuración de variables de entorno y los comandos están en
[`docs/guias/general/`](./docs/guias/general/README.md). La arquitectura está en
[`docs/arquitectura/`](./docs/arquitectura/README.md).

## Flujo de trabajo

1. Haz un fork y crea una rama a partir de `main`.
2. Realiza los cambios y añade o actualiza las pruebas que correspondan.
3. Ejecuta `npm run check` y `npm test` antes de enviar los cambios.
4. Abre un pull request con la plantilla del repositorio.

## Commits

Los mensajes siguen [Conventional Commits](https://www.conventionalcommits.org/es/). Husky y commitlint los validan al
crear el commit.

## Reportar errores y proponer mejoras

Usa las plantillas de issues. Para vulnerabilidades, sigue la [política de seguridad](./SECURITY.md).
